# analyse_clients_marches_powerBI
Analyse clients & marchés – Power BI

 📊 Objectif du projet
Ce projet personnel vise à analyser les performances des clients et des marchés
afin de faciliter la prise de décision commerciale.

📁 Données
Jeu de données public simulant des ventes internationales :
- Colonnes : Date, ClientID, Product, Country, Quantity, Price, Revenue

 🔧 Méthodologie
- Nettoyage et transformation des données avec Power Query
- Création de mesures DAX : CA total, CA moyen par client, Nombre de clients
- Construction de visualisations interactives :
  - KPI Cards pour CA total, Nombre de clients, CA moyen
  - Bar chart pour Top 10 clients
  - Carte ou histogramme pour CA par pays
  - Line chart pour évolution mensuelle des ventes
- Segments (Slicers) pour filtrer par pays et produit

✅ Résultats
- Dashboard interactif permettant de visualiser les clients les plus rentables
- Suivi des ventes par pays et produit
- Aide à la décision pour la stratégie commerciale
